# Ações Rápidas (FAB e Modais)

## Descrição
Para melhorar a UX, o sistema conta com um Floating Action Button (FAB) no canto inferior (Mobile) ou opções na Sidebar (Desktop).

## Modal de Nova Transação
- Centraliza a criação de registros.
- É dividido em 3 Abas (Tabs):
  1. **Despesa**
  2. **Receita**
  3. **Transferência** (Chama o [[Processo - Transferências entre Contas]])
- Permite configurar se a transação é fixa, parcelada ou à vista ([[Processo - Transações Parceladas e Fixas]]).
