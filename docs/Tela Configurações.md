# Tela Configurações

Rota: `/settings`

## Objetivo
Ajustes globais do sistema para o usuário logado.

## Funcionalidades
- Definição do `closing_day` que afeta o [[Processo - Período de Competência]].
- Ajustes de perfil, etc.
- Atualiza a tabela [[DB - Settings]].

## Arquivos Relacionados
- `src/app/(main)/settings/*`
- `src/app/actions/settings.ts`
