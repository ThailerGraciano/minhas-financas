# Tela Autenticação (Login e Register)

Rotas: `/login` e `/register`

## Objetivo
Gerir a autenticação do usuário com o Supabase Auth.

## Funcionalidades
- Fluxo de login e registro via Next.js Server Actions.
- Utilização do `@supabase/ssr` para gestão de sessão (cookies).

## Arquivos Relacionados
- `src/app/(main)/login/*` e `src/app/(main)/register/*`
- `src/app/actions/auth.ts`
- `src/lib/supabase/*`
